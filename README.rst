# EMtools Documentation

Welcome to the official documentation repository for EMtools, an innovative Blender add-on that creates a bridge between Extended Matrix (.graphml files) and Blender's 3D environment.

## Overview

EMtools is a powerful Blender add-on designed to enhance the management and visualization of archaeological data. It enables users to:

- Import .graphML files from Extended Matrix
- Manage proxy files in Blender's 3D environment
- Visualize and modify both geometric and archaeological data
- Handle information at micro and macro scale contexts
- Process single objects or collections
- Manage comprehensive data and paradata

This repository contains the complete documentation for EMtools, including technical specifications, user guides, and best practices. Our goal is to maintain clear, up-to-date documentation that helps users effectively utilize all features of EMtools within Blender.
