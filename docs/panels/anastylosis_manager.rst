Anastylosis Manager (RMSF)
==========================

The Anastylosis Manager panel manages Representation Model Special Find (RMSF) nodes. It allows linking 3D objects to Special Find units defined in the Extended Matrix graph, supporting LOD switching and graph-based special find associations.

.. _RMSFGIF:

.. figure:: ../img/gif/RMSF.gif
   :width: 600
   :align: center

   RMSF panel demonstration

The panel is located in the **EM Annotator** tab and provides the following functionality:

- Link selected 3D objects to an active Special Find node
- Assign Special Find nodes directly from the graph
- Bulk add selected objects as RMSF entries
- Manage LOD (Level of Detail) for RMSF objects
- Track connections between Special Find units and their representation models
