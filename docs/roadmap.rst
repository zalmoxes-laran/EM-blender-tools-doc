Roadmap
=======

This page provides a detailed roadmap for the Extended Matrix Framework and EM Tools development.

Current Development (v1.5)
--------------------------

EM-tools for Blender
^^^^^^^^^^^^^^^^^^^^

**Completed Features**
   - Extension format migration
   - Automatic dependency management
   - GitHub Actions for releases
   - Heriverse export functionality
   - GPU instancing support

**In Progress**
   - Complete multigraph management
   - New labeling system
   - Epoch Manager modernization
   - Soloing mode improvements

**Planned Features**
   - 3D GIS mode implementation
   - Special Finds visualization panel
   - Enhanced documentation

s3Dgraphy Library
^^^^^^^^^^^^^^^^^

.. note::
   The s3Dgraphy library is currently part of EM-tools but will be moved to a separate repository.

**Completed Features**
   - Core JSON configuration files
   - Node type implementations
   - GraphML parser updates
   - Modular architecture

**Planned Features**
   - ParadataGroup node handling
   - Preset vocabulary implementation
   - Standalone publication

Contributing to Roadmap Items
-----------------------------

How to Help
^^^^^^^^^^^

1. **Pick an Item**: Choose from the roadmap issues on GitHub
2. **Discuss**: Comment on the issue to discuss implementation
3. **Implement**: Follow our contribution guidelines
4. **Submit PR**: Create a pull request with your changes

Tracking Progress
^^^^^^^^^^^^^^^^^

- **GitHub Issues**: Each roadmap item has a corresponding issue
- **Projects Board**: Visual kanban for current development
- **Milestones**: Version-based release planning

Suggesting New Features
^^^^^^^^^^^^^^^^^^^^^^^

To suggest additions to the roadmap:

1. Check existing roadmap items
2. Open a new issue with the `enhancement` label
3. Provide detailed use case and implementation ideas
4. Participate in community discussion

Community Input
^^^^^^^^^^^^^^^

The roadmap is shaped by community needs. Join our `Telegram group <https://t.me/UserGroupEM>`_ to participate in roadmap discussions.
