Roadmap
=======

This page provides a detailed roadmap for the Extended Matrix Framework and EM Tools development.

Current Development (v1.5)
--------------------------

EM-tools for Blender
^^^^^^^^^^^^^^^^^^^^

**Completed Features**
   - Extension format migration
   - Automatic dependency management
   - GitHub Actions for releases
   - Heriverse export functionality
   - GPU instancing support
   - Stratigraphy Manager rewrite (formerly US/USV Manager)
   - Anastylosis Manager (RMSF)
   - 3D Document Manager
   - Graph Editor system
   - Proxy Box Creator with paradata enrichment

**In Progress**
   - Landscape mode (multi-graph management)
   - CronoFilter (chronological horizons)
   - Horizon-based filtering and coloring
   - RM visibility sync with horizons
   - Tapestry AI integration (experimental)


**Planned Features**
   - Stable release of landscape mode
   - Enhanced documentation

s3Dgraphy Library
^^^^^^^^^^^^^^^^^

.. note::
   The s3Dgraphy library is currently part of EM-tools but will be moved to a separate repository.

**Completed Features**
   - Core JSON configuration files
   - Node type implementations
   - GraphML parser updates
   - Modular architecture

**Planned Features**
   - ParadataGroup node handling
   - Preset vocabulary implementation
   - Standalone publication

Next Release (v1.6)
-------------------

Major Features
^^^^^^^^^^^^^^

- **3D GIS mode** (moved from 1.5.0)

- **Enhanced Activity Manager**
   - Selection buttons
   - Proxy hiding capabilities
   - Extended information extraction
   - Temporal scope visualization

- **Time Branch Management**
   - Improved branch handling
   - Alternative sequence UI

- **Advanced Visualization**
   - Panorama management
   - Property density algorithms
   - Multiple unit representation

- **Metadata Enhancements**
   - Author information per graph
   - Detailed license display

Suggesting New Features
-----------------------

To suggest additions to the roadmap:

1. Visit the `GitHub issue tracker <https://github.com/zalmoxes-laran/EM-blender-tools/issues>`_
2. Check existing roadmap items
3. Submit a new feature request with detailed use case and implementation ideas
4. Participate in community discussion
